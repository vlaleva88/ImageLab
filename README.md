# Курсов проект "ImageLab"

## Основна идея
Реализация на софтуер, обработващ изображения във формат от семейството NETpbm (.ppm, .pgm или .pbm), като позволява върху тях да бъдат прилагани различни обработки с цел подчертаване на контурите и създаване на нови производни изображения.

Основната цел на проекта е потребителят да може да зарежда, управлява и обработва едно или няколко изображения, като за всяко от тях избира собствена последователност от филтри и обработки.

## Функционалности
```
* load <path> - добавяне на изображение
* add-filter <image> <filter> - добавя филтър към списъка на посочената снимка
* remove-filter <image> <filter-index> - премахва филтъра на позиция filter-index от списъка на снимка номер image
* show-filters <image> - показва филтрите, които ще бъдат приложени към конкретното изображение image
* show-all-filters - показва всички изображения и съответните им филтри
* run <image> - прилага филтрите върху конкретно изображение image и го запазва
* run-all - прилага всички филтри върху всички изображения и ги запазва
* save <image> [output-name] - прилага филтрите върху изображение номер image и го записва с даденото име
(, ако липсва подадено изходно име, резултатът се преименува, като се добавят всички филтри, които са приложени,
върху името на изходния файл)
* quit - прекратява програмата (всички незапазени промени се губят)
```
